# Mail Processing Automation

This is a TypeScript application to **parse and extract information from email files**. Currently, only the .eml file type is supported.

The original and current purpose is extraction of information about deliveries from services such as UPS, USPS, FedEx, etc. It will eventually be extended to support other types of emails and to allow custom parsers.

_This is in very early development and not yet stable as of March 2025. Expect the implementation to change significantly over the coming months._
